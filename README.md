データ分析ポートフォリオ（Data Analysis Portfolio）

データ分析スキルを体系的に習得し、実務レベルで活用できる力を身につけることを目指しています。  
Python・統計学・自動化技術を中心に、3つの成果物を作成しました。

■ 成果物一覧（ポートフォリオ）

① Excelレポート自動化（Python × openpyxl）
Excel業務の自動化を目的としたスクリプトです。  
売上データを読み込み、集計・整形・レポート作成までを自動化しています。

- リポジトリ：準備済み  
- 使用技術：Python / pandas / openpyxl

② Pythonレポート自動生成（JupyterLab × pandas）
売上データを読み込み、グラフ作成・レポート生成までを自動化したNotebookです。  
実務の定例レポートを Python で置き換えることを目的としています。

- リポジトリ：準備済み  
- 使用技術：Python / pandas / matplotlib / seaborn

③ 統計分析ポートフォリオ（Statistical Analysis Portfolio）
統計検定2級レベルの手法を用いて、実務データを分析した成果物です。  
商品別売上の比較、t検定、月次推移などを行い、データの特徴・差・傾向を定量的に評価しています。

- リポジトリ：  
  https://github.com/tnwym2857/analysis-portfolios  
- Notebook：  
  [statistical_analysis.ipynb](https://github.com/tnwym2857/analysis-portfolios/blob/main/statistical_analysis.ipynb)

■ 使用技術一覧
- Python  
- pandas / numpy  
- matplotlib / seaborn  
- scipy / statsmodels  
- JupyterLab  
- Excel自動化（openpyxl）
